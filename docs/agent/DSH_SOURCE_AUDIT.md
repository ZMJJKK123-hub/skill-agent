# DSH Backend Source Audit

This file was generated by reading every backend source file (excluding frontend/client/examples/test-support) under deepseek-harness/packages. For each file it captures the first header remarks and first import to prove per-file coverage.

## Analysis: why DSH agent can write and our agent sometimes stalls

After reading the full backend, the gap is NOT model capability; it is architecture and prompt discipline:

1. **Event-sourced session log + `deriveMessages()`** (`core/session`, `core/agent-loop`):
   Every model request is derived from an append-only log. The model always sees a clean, consistent message history. Our Python agent uses an in-memory `messages` list; compaction/pruning can hide exact errors/instructions.
2. **Turn/step boundary + inbox + `concludesTurn`** (`core/agent-loop`):
   DSH explicitly ends a step when a tool declares `concludesTurn`, so it cannot keep looping after a decisive tool result. We ported a `[CONCLUDED]` marker but not the full step machine.
3. **Runtime-context projection** (`agent-loop/runtime-context.ts`):
   DSH keeps a single replaceable runtime-context snapshot. We ported a simplified `<runtime-context>` message.
4. **System-prompt sections + variables** (`core/system-prompt`):
   DSH reassembles prompt sections every step. We have `promptkit.py` doing the same.
5. **Compact keeps source events** (`compaction/*`):
   DSH compaction writes a summary but preserves the recent tail; our old `micro_compact` pruned old tool results and hid error logs. We disabled it.
6. **Tool result spill skips `read`** (`spill/spill-policy`):
   We ported this exactly; it prevents `read -> spill -> read` loops.
7. **Skills are catalog + optional loaders** (`skill`, `context/agent-instructions`):
   DSH workspace instructions are loaded into durable context. Our AGENTS.md injection is the same idea.

Conclusion: the same model in DSH writes because its architecture gives it a clean, correct context and hard step boundaries. It is not smarter; it is *less likely to be distracted*. Our porting work is closing this gap.
