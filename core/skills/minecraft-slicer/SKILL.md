Slicer

Slicer是一个包含3个程序的Java实用程序组，旨在通过将某些纹理集合拆分为单个纹理来帮助将资源包升级到更高版本。

目前该程序有4个版本：

- 适用于Java版1.14的格式，拆分 ``` particles.png ``` 、 ``` paintings_kristoffer_zetterstrand.png ``` 和 ``` inventory.png ``` 为分开的纹理。
- 适用于Java版1.20.2的格式，拆分大部分用户界面纹理为分开的纹理。
- 适用于Java版1.20.5的格式，拆分 ``` map_icons.png ``` 为分开的纹理。
- 适用于Java版26.2的格式，拆分和重新整理床、告示牌和悬挂式告示牌的纹理。此版本的自动化程序并不完善，需要人工操作处理。
