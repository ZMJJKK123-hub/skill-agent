本条目所述内容仅适用于Java版。
超平坦世界生成预设标签（Flat Level Generator Tags）是超平坦预设的组合。

# 使用

超平坦世界生成预设标签不可被主动调用，它们被游戏用来控制超平坦预设屏幕上可供选择的预设。

# 标签列表

## visible

- 配置可见的超平坦模式生成器。

标签内容：

- #visible（9项） - ``` classic_flat ``` （经典平坦） - ``` tunnelers_dream ``` （挖掘工的梦想） - ``` water_world ``` （水世界） - ``` overworld ``` （主世界） - ``` snowy_kingdom ``` （雪之王国） - ``` bottomless_pit ``` （无底深渊） - ``` desert ``` （沙漠） - ``` redstone_ready ``` （红石俱备） - ``` the_void ``` （虚空）
