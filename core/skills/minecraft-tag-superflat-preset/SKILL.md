# Flat Level Generator Preset Tags

This content applies only to Java Edition.

Flat level generator preset tags are groups of superflat presets.

## Usage

These tags cannot be invoked directly; the game uses them to control which presets are selectable on the superflat preset screen.

## Tag list

### `#visible` (9 entries)

Configured flat world generator presets shown in the selection screen:

- `classic_flat` (Classic Flat)
- `tunnelers_dream` (Tunnelers' Dream)
- `water_world` (Water World)
- `overworld` (Overworld)
- `snowy_kingdom` (Snowy Kingdom)
- `bottomless_pit` (Bottomless Pit)
- `desert` (Desert)
- `redstone_ready` (Redstone Ready)
- `the_void` (The Void)
