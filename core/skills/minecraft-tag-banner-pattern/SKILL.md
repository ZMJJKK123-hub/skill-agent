本条目所述内容仅适用于Java版。
旗帜图案标签（Banner Pattern Tags）是旗帜图案的组合。

# 使用

旗帜图案标签用于控制织布机可绘制的图案。

对于旗帜图案物品而言，这些标签也是它们provides_banner_patterns组件的默认值。

# 标签列表

## no_item_required

- 不需要特定的图案物品就可以在织布机上制作出的图案。

- #no_item_required（32项） - ``` square_bottom_left ``` （右底方） - ``` square_bottom_right ``` （左底方） - ``` square_top_left ``` （右顶方） - ``` square_top_right ``` （左顶方） - ``` stripe_bottom ``` （底横条） - ``` stripe_top ``` （顶横条） - ``` stripe_left ``` （右竖条） - ``` stripe_right ``` （左竖条） - ``` stripe_center ``` （中竖条） - ``` stripe_middle ``` （中横条） - ``` stripe_downright ``` （右斜条） - ``` stripe_downleft ``` （左斜条） - ``` small_stripes ``` （竖条纹） - ``` cross ``` （斜十字） - ``` straight_cross ``` （正十字） - ``` triangle_bottom ``` （底三角） - ``` triangle_top ``` （顶三角） - ``` triangles_bottom ``` （底波纹） - ``` triangles_top ``` （顶波纹） - ``` diagonal_left ``` （右上三角） - ``` diagonal_up_right ``` （左下三角） - ``` diagonal_up_left ``` （右下三角） - ``` diagonal_right ``` （左上三角） - ``` circle ``` （圆形） - ``` rhombus ``` （菱形） - ``` half_vertical ``` （右半方形） - ``` half_horizontal ``` （上半方形） - ``` half_vertical_right ``` （左半方形） - ``` half_horizontal_bottom ``` （下半方形） - ``` border ``` （方框边） - ``` gradient ``` （自上渐淡） - ``` gradient_up ``` （自下渐淡）
