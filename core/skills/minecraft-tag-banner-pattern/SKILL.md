# Banner Pattern Tags

This content applies only to Java Edition.

Banner pattern tags are groups of banner patterns.

## Usage

Banner pattern tags control which patterns can be crafted on the loom. For banner pattern items, these tags are also the default values of their `provides_banner_patterns` component.

## Tag list

### `#no_item_required` (32 entries)

Patterns craftable on the loom without a specific pattern item:

- `square_bottom_left` (Bottom Left Square)
- `stripe_bottom` (Bottom Stripe)
- `cross` (Saltire)
- `circle` (Roundel)
- `border` (Bordered)

For the complete member list, see the tag definition under `data/minecraft/tags/` in mc_java_sources/, or Minecraft Wiki.
