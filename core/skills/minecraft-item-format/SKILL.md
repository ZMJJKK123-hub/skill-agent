关于Java版1.20.5前物品存储数据的格式，请见“物品格式/Java版1.20.5前”；关于基岩版的物品格式，请见“基岩版存档格式/物品格式”。

本条目所述内容仅适用于Java版。
物品堆叠（Item Stack）是游戏使用物品的一种形式，其以统一的格式存储于各个游戏文件中。

# 数据格式

物品数据存在于游戏各处，例如生物物品栏、村民交易内容和物品实体等实体数据，容器物品栏等方块实体的数据。

物品存储有两种方式：

- 带槽位存储：带有[图:字节型]Slot标签指定物品所在的槽位，比如在箱子中。
- 不带槽位存储：物品不在槽位中，而是作为某个属性类的数据或配置项，例如物品实体。

物品存储格式如下：

- [图:NBT复合标签/JSON对象] 根标签

- - [图:字符串]* *id：（命名空间ID）表示某种类的物品堆叠。若未指定，游戏会在加载区块或者生成物品时将其变更为空气。 - [图:NBT复合标签/JSON对象]components：当前物品的组件修订，将修改物品的数据组件信息。 - [图:任意类型]<数据组件ID>：一项组件和其对应的数据，代表物品拥有此组件。设置组件数据时可以不写命名空间，但游戏在导出时会自行加上 ``` minecraft: ``` 前缀。 - [图:NBT复合标签/JSON对象]!<数据组件ID>：存在时，使一个数据组件失效。此复合标签的内容不影响行为。设置组件数据时可以不写命名空间，但游戏在导出时会自行加上 ``` minecraft: ``` 前缀。 - [图:整型]count：（0<值≤物品最大堆叠数量）物品的堆叠数。不存在或无效时则默认为1。

# 物品堆叠

物品堆叠为单纯的物品类型提供了附加的物品数据，包括物品堆叠数量、组件修订等。

当游戏需要使用物品的数据组件数据时，会从两部分获取：一部分来源于物品的默认组件，另一部分来源于物品数据中的组件修订。游戏会在默认组件的基础上进行组件修订，得到实际使用的组件数据。F3 + H显示的高级提示框中的组件数量即实际使用的组件数量。

## 编码格式

游戏定义了多种不同的物品堆叠格式：

- 基础数据格式：必须指定物品ID，物品数量和组件修订可选。此格式是游戏使用最广泛的格式，上文的存储格式即使用此格式。
- 可选数据格式：物品堆叠可以为空，只用于快捷栏。

严格性验证

游戏会在部分场景下对物品进行进行严格性验证。严格性验证分为两步，依次进行，只要其中一个条件不满足则视为验证失败：

- 对物品堆叠组件的验证： - 若物品带有 ``` max_damage ``` 组件，则物品最大堆叠数不能大于1，否则验证失败。 - 若物品带有 ``` container ``` 组件，则要求物品栏内每个物品都通过对物品堆叠数量的验证。 - 若物品带有 ``` bundle_contents ``` 组件，则要求物品栏内每个物品都通过对物品堆叠数量的验证，且总容量不允许超过1组物品。 - 若物品带有 ``` charged_projectiles ``` 组件，则要求物品栏内每个物品都通过对物品堆叠数量的验证。
- 对物品堆叠数量的验证： - 若物品堆叠的数量大于其最大堆叠数，则验证失败。

简而言之，严格性验证使得物品不能既可堆叠又可损坏，其堆叠数量也不能超出最大堆叠数。

游戏会在定义物品堆叠和对既有物品进行组件修订时（如
```
/
give
```

和
```
/
item
```

）进行严格性验证。此外，
```
container
```

、
```
bundle_contents
```

和
```
charged_projectiles
```

组件自身中的所有物品以及其他部分游戏场景使用的物品也会进行严格性验证。

如果严格性验证失败，则游戏会认为这是一个无效物品，对应的命令执行失败，对应的文件加载失败。

## 物品默认组件

未经游戏外部途径修改而获取的物品均拥有默认组件。

在游戏内，物品默认组件可定义为：使用
```
/
give
```

命令且不指定组件修订时所获取物品的组件。

物品默认组件不会序列化为物品数据，因此无法被
```
/
data
```

获取，且当某组件值被设定为默认值时游戏也不会在物品数据中存储此组件。

物品默认组件与物品类型具有强关联性，物品的默认组件不会被其他物品继承。发生物品替换时，如果替换行为会保留原物品的物品堆叠组件，则只有被序列化为物品数据的组件修订会被结果物品继承。

创造模式物品栏中，物品可能还有其他组件，这些组件依靠物品数据生效。当物品现有组件与创造模式物品栏给定组件完全一致时，该物品：

- 创造模式下，在物品提示框中以蓝色字显示其分类。
- 如果物品堆叠上限大于1，则可与创造模式物品栏给定物品堆叠。

物品至少拥有12个默认组件，不同物品的默认组件可能不同。
