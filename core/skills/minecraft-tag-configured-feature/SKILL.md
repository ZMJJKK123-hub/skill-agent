本条目所述内容仅适用于Java版。
已配置的地物标签（Configured Feature Tags）是已配置的地物的组合。

# 使用

已配置的地物标签可以在生物群系中引用，代表生物群系可生成这一类地物。

游戏也内置了一些有特殊用途的标签。

# 标签列表

## can_spawn_from_bone_meal

- 这些地物若定义在生物群系中，则在这些生物群系的草方块上使用骨粉时有概率生成这些地物，而不是矮草丛或高草丛。

- #can_spawn_from_bone_meal（8项） - ``` flower_default ``` - ``` flower_flower_forest ``` - ``` flower_swamp ``` - ``` flower_plain ``` - ``` flower_meadow ``` - ``` flower_cherry ``` - ``` wildflower ``` - ``` flower_pale_garden ```
