数值提供器（Number Provider）允许游戏按一定的规则生成一个特定的数值。其在战利品表系统中使用。

# 定义格式

Java版26.3前，数值提供器只能内联在其他的文件中使用。

Java版26.3起，数值提供器在游戏内使用
```
NUMBER_PROVIDER
```

注册表，数据包路径为
```
number_provider
```

，即所有数值提供器定义文件都需要在
```
data/<
命名空间
>/number_provider
```

目录内定义，数值提供器标签则需要在
```
data/<
命名空间
>/tags/number_provider
```

目录内定义。

数值提供器定义文件使用JSON格式，并具有下列结构：

- [图:整型][图:单精度浮点数][图:NBT复合标签/JSON对象] 数值提供器/JSON文件根节点 - - 如果类型为[图:整型]整数或[图:单精度浮点数]浮点数：则此数值提供器为 ``` constant ``` 类型，[图:整型][图:单精度浮点数]value字段使用此字段的值。 - - 如果类型为[图:NBT复合标签/JSON对象]对象：则表示单个数值提供器，格式如下： - [图:字符串]type：（可能不存在，默认为 ``` uniform ``` ）数值提供器的类型。 - [图:字符串]*type：数值提供器的类型。 - 其他字段与数值提供器类型相关。

# 数值提供器类型

## binominal

返回服从二项分布的随机数。

- [图:NBT复合标签/JSON对象] 数值提供器根节点 - [图:字符串]type： ``` binomial ``` - [图:整型][图:NBT复合标签/JSON对象]*n：进行独立重复的伯努利试验的次数。 - - 数值提供器，见战利品表/数值提供器 - [图:单精度浮点数][图:NBT复合标签/JSON对象]*p：每次试验的成功概率。 - - 数值提供器，见战利品表/数值提供器

## conditional

检查一个条件是否为真并使用对应的数值提供器。

- [图:NBT复合标签/JSON对象] 数值提供器根节点 - [图:字符串]type： ``` conditional ``` - [图:NBT复合标签/JSON对象][图:NBT列表/JSON数组]*predicate：要检查的谓词。 - 见谓词。 - [图:字符串][图:整型][图:单精度浮点数][图:NBT复合标签/JSON对象]*on_true：谓词为真时，要使用的数值提供器。 - - 数值提供器，见战利品表/数值提供器 - [图:字符串][图:整型][图:单精度浮点数][图:NBT复合标签/JSON对象]on_false：谓词为假时，要使用的数值提供器。默认为0。 - - 数值提供器，见战利品表/数值提供器

## constant

返回常数。

- [图:NBT复合标签/JSON对象] 数值提供器根节点 - [图:字符串]type： ``` constant ``` - [图:整型][图:单精度浮点数]*value：一个任意的确切数值。

## enchantment_level

根据战利品上下文提供的魔咒等级计算得出数值。

- [图:NBT复合标签/JSON对象] 数值提供器根节点 - [图:字符串]type： ``` enchantment_level ``` - [图:整型][图:单精度浮点数][图:NBT复合标签/JSON对象]*amount：使用魔咒等级计算数值。 - - 等级依赖函数，见Template:Nbt inherit/level based value/source

## environment_attribute

返回服务端环境属性的值。如果环境属性可以随位置变化，则需要战利品上下文提供的
```
origin
```

作为来源位置进行获取。

- [图:NBT复合标签/JSON对象] 数值提供器根节点 - [图:字符串]type： ``` environment_attribute ``` - [图:字符串]*attribute：（命名空间ID）要获取的环境属性。只能指定数据类型为浮点数或天体角度的环境属性，其他环境属性游戏会因无法转化为浮点数而解析失败。

## number_dispatcher
