本条目所述内容仅适用于Java版。
生物群系标签（Biome Tags）是生物群系的组合。

# 使用

生物群系标签控制了结构生成、生物生成等许多功能。命令
```
/
locate
 biome
```

、
```
/
execute
 if biome
```

等也可以调用生物群系标签。

# 标签列表

- 此标签中的生物群系中生成史莱姆无视史莱姆区块的限制，但受月相的影响。
