青蛙

[[|]][图:Invicon Frog Spawn Egg.png：Minecraft中Frog Spawn Egg的精灵图，描述：青蛙刷怪蛋]

青蛙（Frog）是一种生成于沼泽和红树林沼泽的友好生物。

# 生成

## 自然生成

温带青蛙自然生成于沼泽生物群系，热带青蛙自然生成于红树林沼泽生物群系。

在基岩版中，青蛙生成无亮度要求，空间检测范围为2×2×2。

## 蝌蚪

蝌蚪会在生成20分钟后成长为青蛙，这是生存模式中寒带青蛙唯一的生成途径。给其喂食黏液球可加速成长，每次缩短10%的剩余成长时间。

## 肤色

青蛙有寒带、热带、温带3种变种，分别为绿色、白色、橙色，青蛙的变种取决于其生成时（包括蝌蚪成长为青蛙）所处的生物群系。

在Java版中，游戏通过判断标签以确定生成的青蛙类型，标签
```
#spawns_warm_variant_frogs
```

会使生物群系生成热带青蛙，
```
#spawns_cold_variant_frogs
```

会生成寒带青蛙，其余则是温带青蛙。

# 掉落物

青蛙被玩家或驯服的狼杀死时会掉落1–3 经验值。

# 行为

青蛙在陆地上会漫无目的地缓慢游荡、四处跳跃，在水中则会游泳。在水中，青蛙的移动速度要快得多，且通常会向上游动并停留在水面上。它们的四肢脱离地面时会微微张开。它们还时常鼓动鸣囊。

青蛙最高可以跳8格高。与山羊相似，青蛙在摔落时受到的伤害相较正常水平少5（[图:♥][图:♥][图:♥]）。青蛙会倾向于跳上大型垂滴叶和睡莲。

青蛙可以走上1格高的方块而无需跳跃。

青蛙可以被拴绳拴住。

青蛙不会溺水。

## 捕食

青蛙会捕食小型史莱姆。它们发现目标时会提高移动速度，伸出舌头迅速将其吸入口中，并掉落1个黏液球。

青蛙也会以相同的方式捕食小型岩浆怪。寒带、温带、热带的青蛙吞食岩浆怪后分别会掉落1个青翠、赭黄和珠光变种的蛙明灯。

在Java版中，青蛙捕食时会对猎物造成10（[图:♥][图:♥][图:♥][图:♥][图:♥]）的基础攻击伤害直到其死亡，猎物因此而死亡时没有死亡动画。

在基岩版中，被青蛙吞食的实体会瞬间消失，而没有死亡动画。

## 繁殖

 参见：繁殖 
青蛙会跟随10格内/16格内手持黏液球的玩家。

给两只青蛙喂食黏液球后会使其进入求爱模式，成功繁殖后会掉落1–7 经验值，且双亲在5分钟/1分钟内不能再次喂食和繁殖。其中一只青蛙会怀孕并尝试在周围曼哈顿距离8格内找到一块紧邻水的陆地，移动到该方块后会检查脚下方块毗邻的方块，如果找到上方为空气的水就在该格水的上方产下一格青蛙卵。只要青蛙还处于怀孕状态，没找到合适产卵地点时会等待40游戏刻（2秒）后重新搜索，直到成功产卵为止。

# 你知道吗

- 热带青蛙的原型为现实中的非洲大灰攀蛙，温带青蛙的原型为现实中的牛蛙。
- 青蛙最初被设计为吃掉萤火虫来产生蛙明灯，但在开发者发现一些种类的萤火虫在现实生活中对一些种类的青蛙有毒后，这项计划就被取消了。
- 青蛙和美西螈都是两栖动物，但是青蛙离开水后不会因为脱水而受到伤害并死亡。
- 青蛙拥有独特的游泳动画，在水下也不会溺水而死，但青蛙不属于水生生物。
- 在Java版中，可以通过修改 ``` frog_food.json ``` 让青蛙主动攻击大部分生物，包括玩家和其他青蛙。对于盔甲架和末影龙，青蛙会不断地进行攻击，但无法对其造成伤害也无法吞食。
- 在Minecraft Live 2022的预告片中，青蛙吞掉了一只山羊，这影射了它在基岩版1.18.10.26中因调试代码残留而吞食山羊的行为。
