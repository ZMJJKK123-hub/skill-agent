本条目所述内容仅适用于Java版。
时间线标签（Timeline Tags）是时间线的组合。

# 使用

在维度类型定义文件中，时间线标签被用于指定当前维度类型中所包含的多个时间线。示例文件参见Tutorial:环境属性 § 设置环境属性。

# 标签列表

## in_end

- 在末地活动的时间线。

- #in_end（1项） - ``` #universal ```

## in_nether

- 在下界活动的时间线。

- #in_nether（1项） - ``` #universal ```

## in_overworld

- 在主世界活动的时间线。

- #in_overworld（4项） - ``` #universal ``` - ``` day ``` - ``` moon ``` - ``` early_game ```

## universal

- 在所有维度活动的时间线。

- #universal（1项） - ``` villager_schedule ```
