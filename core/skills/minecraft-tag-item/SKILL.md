# Item Tags

This content applies only to Java Edition.

Item tags are groups of items. They control mob breeding/taming food, tool effectiveness, enchantability, creative inventory groups, piglin bartering, and many other game mechanics — a test succeeds if the item is in the tag.

## Tag list (248 tags)

For every tag, representative members are listed. **For the complete member list of any tag, see the JSON definition under `data/minecraft/tags/item/` in mc_java_sources/, or Minecraft Wiki.**
