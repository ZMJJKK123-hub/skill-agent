# Mob Effect Tags

This content applies only to Java Edition.

Mob effect tags are groups of mob effects.

## Usage

Mob effect tags can currently be referenced by item modifiers and data component predicates.

## Tag list

### `#tradeable` (41 entries)

Potion effects whose tipped arrows the fletcher villager can sell:

- `wind_charged` (Wind Charging)
- `night_vision` (Night Vision)
- `long_night_vision` (Long Night Vision)
- `strong_leaping` (Strong Leaping)
- `slow_falling` (Slow Falling)

For the complete member list, see the tag definition under `data/minecraft/tags/` in mc_java_sources/, or Minecraft Wiki.
