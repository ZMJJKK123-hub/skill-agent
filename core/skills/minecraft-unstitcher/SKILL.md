# Unstitcher

Unstitcher is a Java utility project designed to convert texture packs to the Java 1.5 format. It splits the `terrain.png` and `items.png` texture atlases into individual textures.

## Related tools

- **Texture Ender**: converts texture packs to resource packs
- **Slicer**: splits texture collections for resource pack upgrades
