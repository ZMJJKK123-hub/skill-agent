提示：本条目的主题不是方块实体。

实体（Entity）包括在Minecraft中所有动态的、移动中的对象。

# 一般行为

大部分实体拥有以下性质：

- 占有特定的空间大小。此空间是一个固定长宽高的三维长方体（实体不偏斜时，俯视图为矩形）。
- 当着火时，会受到伤害或消失，实体显示出被火焰包围的样子。
- 可以拥有状态效果，主要由药水产生。

部分实体能够使用命名牌将其重命名。

实体会根据所在位置的亮度等级被照亮。例如，如果矿车斜着撞进一个固体方块中，就会变成黑色（固体方块的亮度永远是0）；射出的箭有时候也会呈现黑色（尤其是几乎水平地卡在了天花板上时）。

## 详细说明

物品展示框、荧光物品展示框、画、拴绳结和坐垫是实体，但与其他实体不同，它们和方块网格对齐，而且不能移动。

### 船和矿车

 参见：运输 
船和矿车会随着时间推移恢复生命值。因此，船和矿车只能在受到快速的攻击后毁坏，而不会在空手攻击且攻击时间与停止时间间隔相同时被毁坏。船和矿车晃动的幅度标明了其当前的生命值。

### 下落的方块

主条目：下落的方块

受重力影响的方块包括沙子、沙砾、可疑的沙子、可疑的沙砾、红沙、滴水石锥、硫黄尖锥、脚手架、铁砧、龙蛋、混凝土粉末和雪。

正常情况下以方块形态存在。当一个方块的支持物消失后，方块会变成实体并掉落，直到撞击在另外一个支持物上方。此时实体会在最近的方块网格中转换成原始方块；如果此方块网格已被非固体方块占用（例如火把或台阶），则实体会转换成物品掉落。

虽然这些方块通常竖直向下落，但是它们的轨迹可以被爆炸和带有黏液块的活塞、水中的气泡柱以及钓鱼竿（仅可移动滴水石锥）改变，也可以通过使用命令或第三方程序修改掉落的方块的速度和方向。重力的影响会使它们变成掉落物，如果下落的方块自生成后存在了至少600游戏刻（30秒）也没有变成方块，或在建造高度外且自生成后存在了至少100游戏刻（5秒），就会直接消失，一般情况下会掉落为对应的方块物品。

当世界生成时，洞穴生成在沙子底下时，游戏不会更新方块状态，而沙子会悬空，直到周围的方块发生变化。这时一个轻微的变化就会触发整个沙子区域的坍塌。在基岩版中，任何在洞穴、在刷怪房天花板或悬崖下产生的受重力影响的方块（例如沙子、沙砾和红沙）都将保持浮空状态，直到受到了方块更新为止。

### 交互

有些实体在被交互时（例如幼年村民、驯服的狼、僵尸、矿车和船），手上物品的交互动作不会被阻止。例如，当玩家手持水桶对着驯服的狼交互，狼会坐下或站起，而桶中的水也会倒出。

### 骑行

主条目：骑乘

实体可以被骑行或与其他实体组合起来。在这种情况，只有组合体中较低/靠外的那个实体会与其他对象相碰撞，并且有权控制组合体的移动。但是也有例外：乘坐着矿车或船或骑着上鞍的马的玩家、骑着鸡的幼年僵尸和骑着马或乘船的骷髅。目前游戏中的常见实体组合体如：

- 载着玩家或生物的船、矿车或运输船。
- 戴上鞍被玩家骑行的猪、马、驴、骡、僵尸马、骷髅马或骆驼。
- 戴上鞍被玩家或僵尸猪灵骑乘的炽足兽。
- 戴上鞍被玩家或尸壳和焦骸骑乘的骆驼尸壳。
- 被玩家骑行的羊驼、鹦鹉螺或坐垫。
- 被玩家或溺尸骑行的僵尸鹦鹉螺。
- 所有骑着蜘蛛或洞穴蜘蛛的骷髅（蜘蛛骑士）。
- 在玩家肩膀上的鹦鹉。
- 骑着鸡（鸡骑士）或其他生物的幼年僵尸或僵尸猪灵。
- 骷髅陷阱马和骑着骷髅马的骷髅。
- 卫道士、掠夺者或唤魔者骑着的劫掠兽。

更高级别的组合体是存在的，如在矿车里骑着猪的玩家。

通过
```
/
ride
```

命令可以使实体骑乘其他实体，或生成骑着其他实体的实体。

在Java版中，通过
```
/
summon
```

命令生成可以在任何实体上面再骑乘一个实体，例如使用
```
/
summon
 spider ~ ~ ~ {Passengers:[{id:"skeleton", equipment:{mainhand: {id:bow} } }]}
```

会生成一个蜘蛛骑士。

如果一个实体正在骑行另一个实体，那么最上层的实体不能传送，因为一旦传送成功，这个实体就会被传送回它骑乘的一个实体。由于游戏通过在新旧位置之间的位置显示实体来平滑移动，因此可能导致在骑乘另一个实体和它们的瞬移位置之间的多个位置处看到该实体。

# 运动

 参见：重力 
一般地，所有实体都具有速度（在Java版中标记除外）、位置和朝向（以经典力学为依据）。一部分实体能被水流推动。包括玩家、生物、船、运输船、物品、被激活的TNT、经验球等。

除恼鬼、末影龙和旁观模式的玩家外的大部分非弹射物实体的判定箱不能穿过固体方块，弹射物的坐标的移动轨迹不会穿过固体方块，但是其判定箱在自身移动时可以部分地卡在固体方块中。大多数实体会占用所在的空间，阻止方块的放置，除了掉落物和经验球会自动让出占用的空间。若实体确实与固体方块处在同一位置，如被掉落的沙子掩埋或被活动的门卡在一起，则可以自由走出方块所在的位置而不能重新进入。（例如，如果玩家和关闭的门卡在一起，头顶无阻碍时，玩家可以向上跳，站在门的下半格上）

## 运动相关数据

一般地，实体有以下3个数据，完全决定了实体的运动：

- 加速度 a（米/刻）：描述实体下一刻速度的变化量。此处的加速度是重力加速度，因为其他加速度的计算非常复杂，而且其相关的公式大多是不固定的。
- “阻力” f：描述实体速度要乘的一个速度，以模拟阻力。竖直方向上的“阻力”和水平方向上的可能不同。“阻力”不应有单位，不然无论如何套公式都会在单位上出错，所以利用公式计算时也需要抛开单位不谈。
- 位置 s：描述实体此时的位置。

进而可以导出以下数据：

- 速度 v（米/刻）：描述实体此时的速度，决定了下一刻实体的位置。这个数据可以由上述3个数据计算得到。
- 终端速度 v∞（米/刻）：Minecraft通过“阻力”使得实体运动的速度不能无限快，而正常情况下，实体运动能达到的最大速度被称为“终端速度”。
- 水平最大位移乘数 k∞（米（米/秒））：此物理量给出了当物体在某一根轴上以某一速度失去加速度后，仅在“阻力”的影响下能到达的最远距离的乘数，其乘以初速度后即得最大位移，即最大位移 s′=k∞v0。

下表就列出了不同实体的重力加速度（即Y轴方向上的加速度）、“阻力”、对3个值的计算顺序（详见下文）、各数据的值、浮点精度类型、终端速度和最大水平移动距离：

### 加速度

加速度分为水平方向（X轴方向和Z轴方向）上的加速度与竖直方向（Y轴方向）上的加速度，其中竖直方向上的加速度就是重力加速度。

重力加速度的值在上表已经给出，除生物以外的水平方向的加速度是0，玩家的加速度由公式 a=a1a2a3+a4 给出。

其中 a1={0.1,在地上,0.02,在空中；a2={1,行走状态,1.3,疾跑状态；a3={0.98,按1个键直行,1,按2个键侧行；a4={0.2,直着走疾跑跳跃,0,其他状态。

### “阻力”

加速度分为水平方向（X轴方向和Z轴方向）上的加速度与竖直方向（Y轴方向）上的加速度。

非生物在两个方向上的“阻力”在上表已经给出。上一刻
```
OnGround
```

属性为1（即在地面上运动）的生物运动时，设该方块的阻力系数为 FB，该生物的摩擦力修正系数为 F，空气阻力修正系数为 A，则竖直方向上的“阻力” fv=1−0.09A，水平方向上的“阻力” fh=(1−0.09A)(1−(1−FB)×F)。

若上一刻生物不在地面上，则只需令阻力系数 FB=0，代入上式即得。

### 速度

我们用 vt 表示这一游戏刻的速度，vt−1 表示上一游戏刻的速度，v0 表示初速度，f为“阻力”，a 为加速度，于是根据“阻力”和加速度的计算程序的顺序不同，在不发生碰撞的情况下，速度的公式有如下几种。每种情况里，第一种是递推公式，根据游戏机制立刻得到，满足所有情况；第二种是通项公式，只有整个运动过程中的加速度 a 和“阻力” f 都不变才可以使用：

“阻力”，加速度：

- vt=vt−1f+a 或 vt=(v0−a1−f)ft+a1−f，

可以从中解出 t=logf(1−f)vt−a(1−f)v0−a；

加速度，“阻力”：

- vt=(vt−1+a)f 或 vt=(v0−af1−f)ft+af1−f，

可以从中解出 t=logf(1−f)vt−af(1−f)v0−af。

速度公式的证明

对于通项公式，以第一种情况为例：

对 vt=vt−1f+a，

两遍同时除以 ft，

得到 vtft=vt−1ft−1+aft，

令 bt=vtft，

于是

bt=bt−1+aft=b0+∑k=1tafk=b0+a∑k=1t(1f)k=b0+af1−(1f)t1−1f⏟等比数列求和=b0+a1−(1f)tf−1=b0+a1−1ftf−1.

将 bt 还原后化简即得。

另外一种情况则只需将 vt=(vt−1+a)f 化成 vt=vt−1f+af 就同理可得。

对于反解时间，是显然的。

跳跃
主条目：跳跃
生物跳跃瞬间，会给予生物竖直方向上一个速度，速度方向竖直向上，大小由公式 v0=pjf+vl+vs 给出，其中j 为跳跃力度，f 为跳跃乘数，p为跳跃蓄力程度，取决于生物种类：

- 对于兔子，p=5021；
- 对于玩家骑乘的马、骷髅马、僵尸马、驴、骡、羊驼和行商羊驼，跳跃蓄力程度由当前跳跃蓄力条的进度决定，最小时为0，最大时为1；
- 对于其他生物，p=1。

如果生物具有等级为l的跳跃提升状态效果，则vl=0.1l。

- 如果生物是尺寸（尺寸= ``` Size ``` +1）为s的岩浆怪，则vs=0.1s。

弹性
主条目：属性/弹性
实体在一定情况下，以一定的速度与方块发生碰撞后，会保留一定的速度，方向变为原来的反向。

对于非生物实体而言，其实体提供的弹性始终为0，且方块计算的弹性碰撞系数会减少20%；对于生物而言，其由弹性属性（
```

```

）决定。

### 位置

我们用 st 表示这一游戏刻的位置，st−1 表示上一游戏刻的位置，s0 表示初位置，f 为“阻力”，a 为加速度，于是根据3个程序运算的顺序不同，位置的公式有如下几种。每种情况里，第一种是递推公式，根据游戏机制立刻得到，满足所有情况；第二种是通项公式，只有整个运动过程中的加速度 a 和“阻力” f 都不变才可以使用：

位置，“阻力”，加速度：

- st=st−1+(v0−a1−f)ft−1+a1−f 或 st=s0+(v0−a1−f)1−ft1−f+at1−f，

可以从中解出 t=1ln⁡fln⁡(a(1−f)(v0(1−f)−a)ln⁡fW((v0(1−f)−a)ln⁡fa(1−f)exp⁡((v0(1−f)−a−(1−f)2(st−s0))ln⁡fa(1−f))))；
“阻力”，加速度，位置：

- st=st−1+(v0−a1−f)ft+a1−f 或 st=s0+(v0−a1−f)(1−ft)f1−f+at1−f，

可以从中解出 t=1ln⁡fln⁡(a(1−f)(v0(1−f)−a)fln⁡fW((v0(1−f)−a)fln⁡fa(1−f)exp⁡(((v0(1−f)−a)f−(1−f)2(st−s0))ln⁡fa(1−f))))；
位置，加速度，“阻力”：

- st=st−1+(v0−af1−f)ft−1+af1−f 或 st=s0+(v0−af1−f)1−ft1−f+aft1−f，

可以从中解出 t=1ln⁡fln⁡(af(1−f)(v0(1−f)−af)ln⁡fW((v0(1−f)−af)ln⁡faf(1−f)exp⁡((v0(1−f)−af−(1−f)2(st−s0))ln⁡faf(1−f))))；
加速度，“阻力”，位置：

- st=st−1+(v0−af1−f)ft+af1−f 或 st=s0+(v0−af1−f)(1−ft)f1−f+aft1−f，

可以从中解出 t=1ln⁡fln⁡(af(1−f)(v0(1−f)−af)fln⁡fW((v0(1−f)−af)fln⁡faf(1−f)exp⁡(((v0(1−f)−af)f−(1−f)2(st−s0))ln⁡faf(1−f))))；
“阻力”，位置，加速度：

- st=st−1+(v0−a1−f)ft+af1−f 或 st=s0+(v0−a1−f)(1−ft)f1−f+aft1−f，

可以从中解出 t=1ln⁡fln⁡(af(1−f)(v0(1−f)−a)fln⁡fW((v0(1−f)−a)fln⁡faf(1−f)exp⁡(((v0(1−f)−a)f−(1−f)2(st−s0))ln⁡faf(1−f))))；
加速度，位置，“阻力”：

- st=st−1+(v0−af1−f)ft−1+a1−f 或 st=s0+(v0−af1−f)1−ft1−f+at1−f，

可以从中解出 t=1ln⁡fln⁡(a(1−f)(v0(1−f)−af)fln⁡fW((v0(1−f)−af)fln⁡fa(1−f)exp⁡(((v0(1−f)−af)f−(1−f)2(st−s0))ln⁡fa(1−f))))。

位置公式的证明

以“位置，‘阻力’，加速度”（第1种情况）为例，首先“阻力”比加速度先计算，所以速度公式采用

vt=(v0−a1−f)ft+a1−f

递推公式由 st=st−1+vt−1 代入速度公式即得；

“‘阻力’，加速度，位置”（第2种情况）的递推公式是 st=st−1+vt，同样代入速度公式即得；接下来2种情况（第3、4种情况）的递推公式同理，只是代入的速度公式不同；

对于“‘阻力’，位置，加速度”（第5种情况），v1=v0f，对于其他正整数 t，vt=(vt−1+a)f，求得其通项公式 vt=v0ft+af1−ft−11−f 代入即可;

对于“加速度，位置，‘阻力’”（第6种情况），v1=v0+a，对于其他正整数 t，vt=vt−1f+a，同样求出递推公式即可。

对于通项公式，以“位置，‘阻力’，加速度”（第1种情况）为例，

可见速度公式 vt=(v0−a1−f)ft+a1−f 是等比数列，对其前 (t−1) 项求和的结果便是 xt−x0 的结果，套等比数列公式即得。

对这一式子 (−v0+vt) 即得“‘阻力’，加速度，位置”（第2种情况）的通项公式；接下来4种情况（第3、4、5、6种情况）的递推公式同理，只是代入的速度公式不同，其中第5、6种情况的通项公式上文已说明。

对于反解时间，以“位置，‘阻力’，加速度”为例，先换元B=v0−a1−f，C=st−s0，则原式变为C=B(1−ft)1−f+at1−f，等号两边同时乘以1−f，然后移项得到Bft+at=B−(1−f)C≜D，令y=ft，u=Bln⁡fay，等式可写成ueu=Bln⁡faexp⁡(Dln⁡fa)，使用朗伯W函数得到u=W(Bln⁡faexp⁡(Dln⁡fa))，回代y=ft=aBln⁡fu，依据t=ln⁡yln⁡f可立刻得到。

其余情况同理可得。

### 终端速度

如果“阻力”的计算比加速度优先，那么终端速度 v∞=−a1−f；否则 v∞=−af1−f。

终端速度公式的证明

以第1种情况为例，根据递推速度公式

vt=vt−1f+a

以及0<f≤1，依不动点可知lim⁡vt存在，只需要联立

v∞=v∞f+a即得终端速度

v∞=lim⁡vn=a1−f。

另一种情况同理可得。

### 水平最大位移乘数

计算公式：如果位置的计算比“阻力”优先，那么水平最大位移乘数 k∞=11−f；否则 k∞=f1−f。

水平最大位移乘数的证明

对于“位置，‘阻力’”的情况，由于 vt=vt−1f，故 vt−1=v0ft−1。由于 st=st−1+vt−1，故 st=s0+∑i=0t−1v0fi，当 t→∞ 时，得 s∞=∑i=0∞v0fi=v0(11−f)=v01−f，其中得到乘数 k∞=11−f；

对于“‘阻力’，位置”的情况，由于 vt=vt−1f，故 vt=v0ft。由于 st=st−1+vt−1，故 st=s0+∑i=1tv0fi，当 t→∞ 时，得 s∞=∑i=1∞v0fi=v0∑i=0∞v0fi=v0f(11−f)=v0f1−f，其中得到乘数 k∞=f1−f。

[图:字符串][图:NBT复合标签/JSON对象][图:NBT列表/JSON数组]CustomName：（文本组件）当前实体的自定义名称。会出现在玩家的死亡消息与村民的交易界面，以及玩家的光标指向的实体的上方。此项实体数据会被视为数据组件custom_name。 - [图:布尔型]CustomNameVisible：表示实体是否一直渲染名称。如果为true，那么名称会一直在它们的上方渲染，而不受光标指向的影响。如果实体没有自定义名称，则渲染默认名称。此项不存在时游戏默认为false。 - [图:字符串][图:NBT复合标签/JSON对象]data：任意NBT数据。字符串形式只用于加载，游戏在保存时只使用复合标签形式。此项实体数据会被视为数据组件custom_data。 - [图:双精度浮点数]*fall_distance：当前实体已经摔落的距离。值越大，实体落地时受到的摔落伤害越大。此项不存在时游戏默认为0。 - [图:短整型]*Fire：正值代表距离火熄灭剩余的时间，负值表示当前实体能够在火中站立而不着火的时间，单位为游戏刻。未着火且未接触火时，玩家为-20游戏刻（1秒），其他实体为-1游戏刻（0.05秒）。此项不存在时游戏默认为0。 -
