本条目所述内容仅适用于Java版。

密度函数（Density Function）是一系列将特定坐标输出为某个值的数学表达式，供噪声设置计算。密度函数定义文件是密度函数在数据包中的数据驱动定义文件。

# 定义格式

密度函数在游戏中使用
```
DENSITY_FUNCTION
```

注册表，数据包路径为
```
worldgen/density_function
```

，即所有的密度函数定义文件都需要在
```
data/<
命名空间
>/worldgen/density_function
```

目录下定义，密度函数标签则需要在
```
data/<
命名空间
>/tags/worldgen/density_function
```

目录下定义。

密度函数定义文件使用JSON格式，并具有下列结构：

- [图:双精度浮点数][图:NBT复合标签/JSON对象] JSON文件根节点 - - 如果类型为[图:双精度浮点数]浮点数，则表示固定值，取值范围为：-1000000.0≤值≤1000000.0。 - - 如果类型为[图:NBT复合标签/JSON对象]对象： - [图:字符串]*type：密度函数类型。 - 依密度函数类型的额外字段，详见下文。其中要求输入密度函数的字段，可以为一个[图:字符串]密度函数ID、一个[图:双精度浮点数]密度函数常数值或一个[图:NBT复合标签/JSON对象]密度函数的JSON格式。

# 定义行为

密度函数定义数据仅在服务端启动时加载一次，使用
```
/
reload
```

命令不可以使密度函数定义被重新加载，而必须重启服务端。

密度函数可以根据一定的运算法则将一个坐标转换为一个数，主要供噪声设置使用。密度函数的常数取值不允许超过区间
```
[-1000000.0, 1000000.0]
```

。

## interpolated

根据周围元胞（Cell）的密度函数值，对元胞里的每个方块进行插值。每个元胞的大小为
```
size_horizontal * 4
```

```
size_vertical * 4
```

。
