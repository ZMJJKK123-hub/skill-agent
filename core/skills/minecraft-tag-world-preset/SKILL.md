# World Preset Tags

This content applies only to Java Edition.

World preset tags are groups of world presets.

## Usage

These tags cannot be invoked directly; the game uses them to control which world presets appear on the world creation screen.

## Tag list

### `#extended` (2 entries)

World presets shown in the "World" button when holding Alt:

- `#normal`
- `debug_all_block_states` (Debug Mode)

### `#normal` (5 entries)

World presets shown in the "World" button by default:

- `normal` (Normal)
- `flat` (Flat)
- `large_biomes` (Large Biomes)
- `amplified` (Amplified)
- `single_biome_surface` (Single Biome)
