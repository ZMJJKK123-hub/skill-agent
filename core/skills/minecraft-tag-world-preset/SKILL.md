本条目所述内容仅适用于Java版。
世界预设标签（World Preset Tags）是世界预设的组合。

# 使用

世界预设标签不可被主动调用，它们被游戏用来控制创建世界屏幕上可供选择的世界预设。

# 标签列表

## extended

- 按住Alt键时，在“世界”按钮中展示的世界预设。

- #extended（2项） - ``` #normal ``` - ``` debug_all_block_states ``` （调试模式）

## normal

- 默认情况下，在“世界”按钮中展示的世界预设。

- #normal（5项） - ``` normal ``` （默认） - ``` flat ``` （超平坦） - ``` large_biomes ``` （巨型生物群系） - ``` amplified ``` （放大化） - ``` single_biome_surface ``` （单一生物群系）
