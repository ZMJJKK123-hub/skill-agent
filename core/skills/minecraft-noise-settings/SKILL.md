本条目所述内容仅适用于Java版。
噪声设置（Noise Settings），全称噪声生成器设置（Noise Generator Settings），定义了由噪声生成器生成的世界的基础地形和表面规则。噪声设置定义文件是噪声设置在数据包中的数据驱动定义文件。

# 定义格式

噪声设置在游戏中使用
```
NOISE_SETTINGS
```

注册表，数据包路径为
```
worldgen/noise_settings
```

，即所有的噪声设置定义文件都需要在
```
data/<
命名空间
>/worldgen/noise_settings
```

目录下定义，噪声设置标签则需要在
```
data/<
命名空间
>/tags/worldgen/noise_settings
```

目录下定义。

噪声设置定义文件使用JSON格式，并具有下列结构：

- [图:NBT复合标签/JSON对象] JSON文件根对象 - [图:整型]* *sea_level：维度的海平面高度。 - [图:布尔型]* *aquifers_enabled：是否启用含水层。 - [图:布尔型]* *ore_veins_enabled：是否启用矿脉。 - [图:布尔型]* *disable_mob_generation：是否禁止初始动物生成。 - [图:布尔型]* *legacy_random_source：是否使用1.18前旧的随机数生成器生成世界。 - [图:字符串][图:NBT复合标签/JSON对象]* *default_block：维度的默认方块。 - - 方块状态，见Template:Nbt inherit/block state/source - [图:字符串][图:NBT复合标签/JSON对象]* *default_fluid：维度的默认流体。 - - 方块状态，见Template:Nbt inherit/block state/source - [图:NBT列表/JSON数组]* *spawn_target：（可以为空）一个生物群系参数区间的数组，用于决定玩家出生点的环境条件。会选取距离(0,0)不超过2560格的多个点，获取其环境条件噪声值（深度和偏移恒为0），计算(x2+z2)2390625+∑i=16di2，其中di代表该点处某种生物群系参数的值到本数组中对应值的区间的距离（d=infa∈A|x−a|）。计算结果最小的位置就是最佳位置。玩家出生位置会在这个位置附近。 - [图:NBT复合标签/JSON对象]：一个范围区间。 - - 生物群系噪声值参数，见Template:Nbt inherit/parameter point/source - [图:NBT复合标签/JSON对象]* *noise：世界噪声参数。 - [图:整型]* *min_y：（-2032≤值≤2031，必须为16的倍数）地形生成的最低高度。 - [图:整型]* *height：（0≤值≤2032-[图:整型]min_y，必须为16的倍数）地形生成的总高度。 - [图:整型]* *size_horizontal：（1≤值≤4）采样计算时每个元胞的水平长度。 - [图:整型]* *size_vertical：（1≤值≤4）采样计算时每个元胞的纵向高度。 - [图:NBT复合标签/JSON对象]* *noise_router：将密度函数与世界生成绑定的噪声参数。每个密度函数都可以是命名空间ID、密度函数常量或内联格式。 - [图:字符串][图:双精度浮点数][图:NBT复合标签/JSON对象]* *preliminary_surface_level：代表预处理地表高度的2D密度函数，将影响含水层和表面规则的放置。 - [图:字符串][图:双精度浮点数][图:NBT复合标签/JSON对象]* *final_density：最终密度。大于0的区域将放置默认方块并被表面规则替换，小于0的区域将放置空气并被含水层替换。 - [图:字符串][图:双精度浮点数][图:NBT复合标签/JSON对象]* *barrier：影响含水层是否在流体与空气之间放置阻挡方块，值越大概率越大。 - [图:字符串][图:双精度浮点数][图:NBT复合标签/JSON对象]* *fluid_level_floodedness：影响含水层放置流体的概率，大于1的值被视为1，小于0的值被视为0。 - [图:字符串][图:双精度浮点数][图:NBT复合标签/JSON对象]* *fluid_level_spread：影响含水层放置流体的高度，此值越低越不可能放置含水层。 - [图:字符串][图:双精度浮点数][图:NBT复合标签/JSON对象]* *lava：当绝对值大于0.3时含水层在Y=-58与海平面之间放置熔岩而不是默认流体。 - [图:字符串][图:双精度浮点数][图:NBT复合标签/JSON对象]* *vein_toggle：大于0时则尝试放置铜矿脉，否则尝试放置铁矿脉。 - [图:字符串][图:双精度浮点数][图:NBT复合标签/JSON对象]* *vein_ridged：小于0时不放置矿脉方块。 - [图:字符串][图:双精度浮点数][图:NBT复合标签/JSON对象]* *vein_gap：影响矿脉实际放置的方块，如果大于-0.3，并且随机数小于从0.4到0.6映射到0.1到0.3的[图:字符串][图:双精度浮点数][图:NBT复合标签/JSON对象]vein_toggle的绝对值，则会放置矿石块，且有2%的概率变为粗金属块。否则，将放置矿脉类型对应的石块。 - [图:字符串][图:双精度浮点数][图:NBT复合标签/JSON对象]* *temperature：生物群系温度函数。此参数同下方共六个参数也负责了多噪声型生物群系计算时使用的噪声参数。 - [图:字符串][图:双精度浮点数][图:NBT复合标签/JSON对象]* *vegetation：生物群系湿度函数。 - [图:字符串][图:双精度浮点数][图:NBT复合标签/JSON对象]* *continents：生物群系大陆性函数。 - [图:字符串][图:双精度浮点数][图:NBT复合标签/JSON对象]* *erosion：生物群系侵蚀度函数。 - [图:字符串][图:双精度浮点数][图:NBT复合标签/JSON对象]* *depth：生物群系深度函数。 - [图:字符串][图:双精度浮点数][图:NBT复合标签/JSON对象]* *ridges：生物群系奇异度函数。 - [图:NBT复合标签/JSON对象]* *surface_rule：（不能为空）替换维度默认方块。 - # 定义行为

噪声设置定义数据仅在服务端启动时加载一次，使用
```
/
reload
```

命令不可以使密度函数定义被重新加载，而必须重启服务端。

噪声设置可以在噪声生成器中使用，为维度提供更复杂的世界生成。

噪声设置决定了世界的基础地形，包括噪声洞穴、含水层和矿脉放置。

在地形生成阶段，游戏会先使用最终密度函数是否大于0初步判断一个坐标应该放置维度默认方块还是空气。维度默认方块将被矿脉和表面规则依次替换；而Y=-58以上且海平面或地表以下的空气将被含水层替换，低于Y=-58的空气始终被熔岩替换。

# 内置噪声设置

游戏内置了7个噪声设置：

- ``` minecraft:overworld ``` ：用于一般的主世界生成。
- ``` minecraft:amplified ``` ：用于放大化主世界生成。
- ``` minecraft:large_biomes ``` ：用于巨型群系的生成。
- ``` minecraft:nether ``` ：用于常规的下界生成。
- ``` minecraft:caves ``` ：用于主世界洞穴生成。
- ``` minecraft:end ``` ：用于常规的末地生成。
- ``` minecraft:floating_islands ``` ：用于浮岛的生成。
