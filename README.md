# MOD Forge —— 一句话生成完整可玩的 Minecraft Forge MOD

输入一句中文需求（如"做一个红宝石剑，攻击力 7"），AI 自动完成**写代码、画纹理、写配方、编译、游戏内自动化测试、真实客户端验证**，最终交付一个可直接放进 `.minecraft/mods/` 的 jar 文件。全程网页操作，无需写一行代码。

---

## 一、环境要求

| 项目 | 要求 |
|---|---|
| 操作系统 | Windows 10/11（客户端自动化依赖 Windows API） |
| Java | JDK 21（`java -version` 能看到 21.x 即可） |
| Python | 3.10+，并安装依赖：`pip install -r requirements.txt` |
| 模型 API Key | 智谱 / DeepSeek 等 OpenAI 兼容服务的 Key（二选一即可，见下） |

> 首次构建 MOD 时 Gradle 会自动下载依赖（几分钟），之后有缓存就快了。

## 二、三步启动

```bat
cd server_app
python server.py
```

浏览器打开 **http://127.0.0.1:8000** 即可使用。

> 想让局域网其他机器访问？本服务默认监听 `0.0.0.0:8000`，用 `http://<你的IP>:8000` 访问即可。

## 三、首次使用配置（约 1 分钟）

1. **注册/登录**：点右上角「登录」→ 切到「注册」→ 填用户名密码 →「注册并登录」
2. **填 API Key**：点左下角「⚙️ 设置」→「模型」页，填入你的 Key 并应用。三种常见组合：

| 你有的服务 | Base URL | 模型名 |
|---|---|---|
| 智谱 Coding Plan | `https://open.bigmodel.cn/api/coding/paas/v4` | `glm-5.3` / `GLM-5.3-flash` |
| DeepSeek 官方 | `https://api.deepseek.com` | `deepseek-chat` 等 |
| 智谱普通（按量） | `https://open.bigmodel.cn/api/paas/v4` | `glm-4.6v-flash` 等 |

3. **建议开启**（同一设置页）：
   - **全自动模式**：agent 遇到选择题不再停下来问你，用合理默认值继续
   - **权限**保持「完全访问」（需要放方块、编译等真实操作）

## 四、生成你的第一个 MOD

1. 主界面输入框输入任务（以 `/mod` 开头进入 MOD 制造模式），例如：

   > /mod 做一个红宝石剑（Ruby Sword）：攻击力 7、耐久 500，合成配方用铁锭+红石，带创造模式标签页、中英文名称和清晰纹理

2. 点「发送」→ 系统自动：
   - 创建独立工作区（复制 Forge 1.21.11 模板）
   - AI 学习相关知识 → 写 Java 代码与资源 → 生成纹理
   - 编译 → 运行 **GameTest 自动化测试** → 修复报错循环
   - （可选）启动**隐形 Minecraft 客户端**实际进入游戏验证图标渲染
3. 看到「完成 ✓」后，两个按钮任你取：
   - **⬇ 下载 mod jar** → 放进 `.minecraft/mods/` 直接玩
   - **⬇ 下载源码 zip** → 完整 Gradle 工程，可继续二开
4. 左侧栏会保留所有历史会话（带 `jar ✓` 标记），随时回看过程或重新下载

任务描述写得越具体越好：**物品名、数值（攻击力/耐久/饥饿值）、合成方式、是否需要客户端内验证**。

## 五、客户端验证说明（完全后台，不打扰你）

MOD 的"实际可玩性"由系统**在真实游戏客户端里自动验证**：放置方块、发放物品、打开 GUI、截图并让视觉模型判定渲染是否正确。

- 验证期间客户端窗口**自动隐形**（不抢焦点、点击穿透），你照常使用电脑
- 该能力默认开启；如想亲眼看到游戏画面，在环境变量设 `DSH_MC_BACKGROUND=0` 后重启服务
- 低配服务器可设 `DSH_DISABLE_CLIENT_TOOLS=1` 剔除所有客户端/游戏工具，只保留编译+GameTest 验证

## 六、常见问题

| 现象 | 处理 |
|---|---|
| 提示"API Key 为空" | 服务重启后旧会话的 Key 不保留（安全设计），在设置里重填或新建会话 |
| 构建失败反复 | 正常迭代现象，agent 会读错误日志自动修复；复杂任务可能需要多轮 |
| GameTest 报 split-package 崩溃 | 测试类必须在 `com.<modid>.tests` 子包（agent 会自动处理） |
| 想要识图验证但提示未开启 | 设置页「识图模式」开启，并配视觉模型 Key（智谱 `glm-4.6v-flash` 免费档可用） |
| 端口 8000 被占 | 关闭旧的 python 进程，或改 `server.py` 末尾的端口号 |

## 七、目录速查

```
server.py            FastAPI 主服务（本文件即整站）
run_task.py          每个任务的独立子进程入口（互不干扰、崩溃可恢复）
core/                Agent 引擎（主循环/工具/上下文压缩/多 Agent 协作）
mod_templates/       Forge 1.21.11 工程模板 + starter 代码模板 + AgentBridge
data/                运行时数据（会话/用户；可整目录删除，重启自动重建）
artifacts/           历史验证通过的成品 jar 归档
docs/                参考文档（错误清单、工具手册等，agent 运行时会读）
```
