# Tool: describe_item_texture

## 用途
生成物品纹理Prompt描述。

## 输入
```json
{
  "item_name": "dragon_tooth",
  "visual_description": "弯曲的龙牙，乳白色带血丝",
  "style": "vanilla_16x16"
}
```

## 输出
```json
{
  "path": "assets/modid/textures/item/dragon_tooth.png",
  "size": "16x16",
  "prompt": "A curved dragon tooth, ivory white with blood-red veins, Minecraft vanilla 16x16 pixel art icon, transparent background, centered",
  "prompt_zh": "弯曲的龙牙，乳白色带血红色脉络，Minecraft原版16x16像素图标，透明背景，居中"
}
```
