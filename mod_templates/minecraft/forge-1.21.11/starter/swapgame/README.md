# SwapGame Starter

Copy `SwapGameMod.java` into `src/main/java/com/swapgame/` to get a compiling base
(registers `swapgame:chaos_book`). Then expand with:

- `ChaosBookItem` (right-click opens config GUI)
- `SwapGameState` (server-side game state, hidden timer, random swaps)
- network payloads for HUD sync
- client HUD screen

This starter is a starting point; the agent should keep writing until the full
feature set and `dist/swapgame-1.0.0.jar` exist.
