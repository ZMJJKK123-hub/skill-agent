# Starter Templates

This directory contains optional, copy-paste starter files for common MOD features.
They are **not compiled** by Gradle because they live outside `src/`.

## How to use

1. Read the matching subfolder (e.g. `block/`).
2. Copy/rename the files you need into `src/` (and into `assets/<modid>/...` / `data/<modid>/...`).
3. Fill in `modid`, `name`, and any placeholders.
4. Delete any starter files you do **not** use — they are optional and safe to remove.

If a starter is not relevant to the current task, ignore or delete it.
