# Tools Starter

For a tool set (sword/pickaxe/axe/…), copy `CopperToolsMod.java` into
`src/main/java/com/<pkg>/CopperToolsMod.java`, then rename package/modid/item ids.

Also copy the item rendering resources from `starter/item/` for each item:
- `items/<id>.json`
- `models/item/<id>.json` (use `handheld_model.json.template` for tools)
- `textures/item/<id>.png` (use PNG generator snippet)

If this starter is not relevant, delete this folder.
